## Вовед

**Реверс** е документ за привремено издавање на опрема на вработени или партнери со обврска за враќање. Модулот `eskon_reverse` овозможува:

- Издавање опрема со рок за враќање
- Автоматски потсетувања пред истек на рокот
- Следење кој има која опрема
- Централизирано управување со локации

### Терминологија

| Термин | Опис |
|--------|------|
| Реверс | Документ за издавање опрема |
| Враќање на Реверс | Документ за враќање на опрема |
| Location Provider | Сервис за автоматско креирање локации |
| Рок за враќање | Датум до кога опремата треба да се врати |

## Пристап до модулот

### Главно мени

```
Inventory → Операции → Реверси
```

### Брзи линкови

| Акција | Патека |
|--------|--------|
| Нов реверс | Inventory → Operations → Реверси → New |
| Враќање | Inventory → Operations → Реверси → Враќања |
| Преглед залиха | Inventory → Reporting → Locations |
| Поставки | Inventory → Configuration → Settings |

## Конфигурација

### Основни поставки

Оди во **Inventory → Configuration → Settings** и најди ја секцијата **Location Provider**:

| Поставка | Опис | Препорачано |
|----------|------|-------------|
| Автоматски за вработени | Креира локација при нов вработен | ✓ Вклучено |
| Автоматски за возила | Креира локација при ново возило | ✓ Вклучено |
| Автоматски за тимови | Креира локација при нов тим | По потреба |
| Автоматски за партнери | Креира локација при нов партнер | По потреба |
| FSM приоритет | Приоритет за теренска работа | Возило |

### FSM приоритет (за Field Service)

Оваа поставка одредува од која локација прво се земаат материјали:

| Опција | Приоритет |
|--------|-----------|
| **Возило** | Возило → Вработен → Магацин |
| **Вработен** | Вработен → Возило → Магацин |
| **Тим** | Тим → Возило → Вработен → Магацин |

## Издавање на опрема

### Издавање на вработен

**Пример:** Издавање лаптоп на Ѓорѓе Коцев

#### Чекор 1: Креирај нов Реверс

1. Оди во **Inventory → Operations → Transfers**
2. Кликни **"New"**
3. **Operation Type**: Избери `Реверс`

#### Чекор 2: Пополни податоци

| Поле | Вредност | Забелешка |
|------|----------|-----------|
| Partner | Ѓорѓе Коцев | Избери вработен |
| Тип на примател | Вработен | ВАЖНО за правилна локација |
| Рок за враќање | 2025-01-15 | Датум до кога треба да врати |
| Source Location | ESKON-GM/Stock | Автоматски |
| Destination | Вработени/... | Автоматски според вработен |

#### Чекор 3: Додади опрема

Во табелата **Operations** кликни **"Add a line"**:

| Product | Quantity |
|---------|----------|
| Dell Latitude 5540 | 1 |
| Полнач за лаптоп | 1 |
| Торба за лаптоп | 1 |

#### Чекор 4: Потврди

1. Кликни **"Validate"**
2. Реверсот добива број: `ESGM/REV/00001`
3. Опремата е сега на локација на вработениот

---

### Издавање на партнер/клиент

**Пример:** Издавање демо опрема на клиент

#### Чекор 1-2: Исто како горе

Креирај нов Реверс

#### Чекор 3: Пополни за партнер

| Поле | Вредност |
|------|----------|
| Partner | ЕСКОН-ИНЖЕНЕРИНГ ДООЕЛ |
| Тип на примател | **Партнер/Клиент** |
| Рок за враќање | 2025-02-01 |
| Destination | Партнери/ЕСКОН-ИНЖЕНЕРИНГ... |

> **Напомена:** Ако партнерот нема локација, системот автоматски ја креира.

#### Чекор 4: Додади опрема

| Product | Quantity |
|---------|----------|
| Метален носач на кабли | 10 |
| Кабел PP-Y 4x16мм | 100 |

#### Чекор 5: Потврди

Кликни **"Validate"**

## Следење на опрема

### Преглед по локации

1. Оди во **Inventory → Reporting → Locations**
2. Филтрирај по:
   - **Ресурси/Вработени** - за опрема кај вработени
   - **Ресурси/Возила** - за опрема во возила
   - **Партнери** - за опрема кај клиенти

### Следење задоцнети враќања

#### Филтри во листата на Реверси:

| Филтер | Опис |
|--------|------|
| Задоцнети | Реверси со поминат рок |
| За враќање оваа недела | Предстојни враќања |
| Сите отворени | Сè уште невратени |

#### Визуелни индикатори:

| Боја на датум | Значење |
|---------------|---------|
| 🔴 Црвено | Поминат рок - ИТНО! |
| 🟠 Портокалово | 3 дена или помалку |
| ⚪ Нормално | Повеќе од 3 дена |

### Автоматски потсетувања

Системот автоматски:

1. **3 дена пред рок** - Испраќа потсетување
2. **На денот** - Креира To-Do активност
3. **По рокот** - Означува како задоцнето

## Враќање на опрема

### Метод 1: Преку Враќања (препорачано)

1. Оди во **Inventory → Operations → Реверси → Враќања**
2. Кликни **"New"**
3. **Operation Type**: `Враќање на Реверс`
4. Пополни:
   - **Source**: Локација на вработен/партнер
   - **Destination**: ESKON-GM/Stock
5. Додади производи и количини
6. Кликни **"Validate"**

### Метод 2: Internal Transfer

1. **New Transfer** → Operation Type: **Internal Transfer**
2. **Source Location**: `Вработени/Ѓорѓе Коцев`
3. **Destination Location**: `ESKON-GM/Stock`
4. Додади линии со производи
5. **Validate**

### Пример: Враќање на лаптоп

| Поле | Вредност |
|------|----------|
| Source | Вработени/Ѓорѓе Коцев |
| Destination | ESKON-GM/Stock |
| Product | Dell Latitude 5540 |
| Quantity | 1 |

## Автоматски локации

### Хиерархија на локации

```
Physical Locations/
├── Ресурси/                          (view)
│   ├── Вработени/                    (view)
│   │   ├── Вработен - Ѓорѓе Коцев    (internal)
│   │   ├── Вработен - Љубе Јовески   (internal)
│   │   ├── Сервисен тим              (internal)
│   │   └── Тест лабораторија         (internal)
│   ├── Возила/                       (view)
│   │   ├── Возило - SR-123-AB        (internal)
│   │   └── Возило - SK-456-CD        (internal)
│   └── Тимови/                       (view)
│       └── (FSM тимови)              (internal)
└── Партнери/                         (view)
    ├── Партнер - ЕСКОН-ИНЖЕНЕРИНГ    (internal)
    └── Партнер - Test Customer       (internal)
```

### Кога се креираат автоматски?

| Ресурс | Се креира при | Услов |
|--------|---------------|-------|
| Вработен | Креирање на нов вработен | Ако е вклучено во Settings |
| Возило | Креирање на ново возило | Ако е вклучено во Settings |
| Тим | Креирање на нов FSM тим | Ако е вклучено во Settings |
| Партнер | Прв реверс кон партнер | Ако е вклучено во Settings |

## Најдобри практики

### ✅ Препораки

1. **Секогаш внеси реален рок** - за да работат потсетувањата
2. **Провери Inventory Report** - редовно за преглед на опрема
3. **Користи го правилниот тип** - Вработен vs Партнер
4. **Опиши ја опремата** - со сериски број ако има

### ❌ Избегнувај

1. Издавање без рок за враќање
2. Мешање на вработени и партнери во ист реверс
3. Игнорирање на потсетувањата
4. Враќање на погрешна локација

## Често поставувани прашања

### П: Што ако вработениот нема локација?

**О:** Ако е вклучено автоматско креирање во Settings, локацијата се креира автоматски при реверс. Ако не е вклучено, мора рачно да ја креирате.

### П: Може ли да издадам на повеќе вработени одеднаш?

**О:** Не, секој реверс е за еден примател. Креирајте посебен реверс за секој вработен.

### П: Што се случува при деактивирање на вработен?

**О:** Локацијата останува, но опремата мора да се врати пред деактивирање.

### П: Како да најдам сите реверси за еден вработен?

**О:** Во листата на Реверси, филтрирај по Partner = име на вработен.

### П: Може ли да го смениам рокот после потврда?

**О:** Не директно. Креирај враќање и потоа нов реверс со нов рок.

## Технички детали

### Нумерирање

- **Реверс**: `ESGM/REV/00001`, `ESGM/REV/00002`...
- **Враќање**: `ESGM/REV-RET/00001`...

### Picking Types

| Код | Име | Опис |
|-----|-----|------|
| REV | Реверс | Издавање опрема |
| REV-RET | Враќање на Реверс | Враќање опрема |

### XML IDs на локации

```
eskon_reverse.stock_location_resources    # Ресурси
eskon_reverse.stock_location_employees    # Вработени
eskon_reverse.stock_location_vehicles     # Возила
eskon_reverse.stock_location_teams        # Тимови
eskon_reverse.stock_location_partners     # Партнери
```
