# Реверс - Позајмување на опрема

Модул за управување со привремено издавање на опрема во Одоо 18.

## Функционалности

- ✅ **Employee Locations** - Локации за следење опрема кај вработени
- ✅ **Реверс Picking Type** - Нов тип на операција за позајмување
- ✅ **Автоматско нумерирање** - ESGM/REV/00001, ESGM/REV/00002...
- ✅ **Враќање на Реверс** - Посебен тип за враќање
- ✅ **Извештаи** - Опрема кај вработени

## Инсталација

1. Копирајте го модулот во `addons` директориумот
2. Рестартирајте Одоо
3. Одете во Apps → Update App List
4. Инсталирајте "Реверс - Позајмување на опрема"

```bash
./odoo-bin -d database -i eskon_reverse
```

## Работен тек

### 1. Издавање (Позајмување)

```
Inventory → Операции → Реверси → New

From: WH/Stock
To: Вработени/Тест лабораторија
Product: Камера XYZ
Quantity: 2

→ Validate

Резултат: ESGM/REV/00001
```

### 2. Следење

```
Inventory → Операции → Реверси → Опрема кај вработени

Ќе видите:
- Тест лабораторија: Камера XYZ (2 units)
- Сервисен тим: Мултиметар (1 unit)
```

### 3. Враќање

```
Inventory → Операции → Реверси → Враќања → New

From: Вработени/Тест лабораторија
To: WH/Stock
Product: Камера XYZ
Quantity: 2

→ Validate
```

## Локации

Модулот креира:

```
Physical Locations/
└── Вработени/
    ├── Тест лабораторија
    ├── Сервисен тим
    └── Продажен тим
```

Можете да додадете повеќе локации за индивидуални вработени.

## Picking Types

- **Реверс** (REV) - За издавање на опрема
- **Враќање на Реверс** (REV-RET) - За враќање на опрема

## Мени

```
Inventory → Операции → Реверси
├── Реверси (Издавања)
├── Враќања
└── Опрема кај вработени
```
